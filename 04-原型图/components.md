# 组件规范（与最终实现 1:1 对齐）

所有组件基于 Element Plus 主题变量覆盖，覆盖值以 `design-system.md` 为准。

## 1. 按钮

| 类型 | 高度 | 内边距 | 圆角 | 背景 / 边框 | 文字 |
|---|---|---|---|---|---|
| 主按钮 primary | 32 | 0 16 | 6 | `#15344A` / 无 | `#FFF` 14px |
| 次按钮 default | 32 | 0 16 | 6 | `#FFF` / `1px #DCE5E8` | `#1C2B33` |
| 文字按钮 link | 32 | 0 8 | 6 | 透明 | `#2D5B6B` |
| 危险按钮 danger | 32 | 0 16 | 6 | `#FFF` / `1px #B03035` | `#B03035` |
| 禁用 | 32 | — | 6 | `#EDF2F4` | `#8A9AA2` |

- 行内最多「查看 + 2 个高频操作」，其余进「更多」下拉。
- 危险操作二次确认，普通取消不弹强提醒。
- 批量按钮默认隐藏，勾选数据后出现。

## 2. 表单

- 标签右对齐，宽 110px，字号 13，颜色 `#5B6E77`。
- 输入框高 32px，圆角 6px，边框 `#DCE5E8`，聚焦边框 `#237A8B` + 2px 外发光 `rgba(35,122,139,.15)`。
- 单列宽度 360–520px；两列表单每列 380px，间距 24px。
- 搜索区下拉框宽 200px（区间 180–240px）。
- 必填项前置红色 `*`，校验失败在字段下方 12px 提示，文案具体到如何改。
- 长表单分组：基础信息 / 资质材料 / 供货能力 / 联系人，组间 24px。
- 关闭未保存表单时弹「离开将丢失未保存内容」。

## 3. 表格

- 表头：`#F3F7F8` 底，13px，`#5B6E77`，无固定列宽，最小宽度按内容（`min-width` 90–160px）。
- 行高 44px，斑马纹关闭，hover 行底 `#F7FBFC`。
- 边框仅横向 1px `#E8EEF0`。
- 编号、状态、日期、操作列 `white-space: nowrap`，保持单行。
- 超出容器横向滚动，不压缩列。
- 分页：右对齐，默认 10 条，可切 20/50，切换筛选后回到第 1 页。
- 空状态：说明原因 + 下一步按钮（清空筛选 / 新建）。

## 4. 卡片

- 白底，1px `#DCE5E8` 边框，圆角 8px，内边距 20px，无阴影。
- 标题 16px/600，右上角放操作与时间范围。
- 看板指标卡：高 92px，左标题 13px 灰，右数值 28px 深蓝 tabular-nums，底部 12px 同比说明。

## 5. 标签（状态）

- 高 22px，内边距 0 8，圆角 4px，字号 12。
- 六类：success `rgba(45,122,88,.10)` / `#2D7A58`；warning `rgba(169,112,31,.12)` / `#A9701F`；danger `rgba(176,48,53,.10)` / `#B03035`；info `rgba(35,122,139,.10)` / `#237A8B`；neutral `#EDF2F4` / `#5B6E77`；primary `rgba(21,52,74,.08)` / `#15344A`。
- 等级徽标：24×24 方块，圆角 4，A 绿 / B 蓝 / C 橙 / D 红，白字 13px/600。

## 6. 弹窗与抽屉

- 审批、流转、详情统一使用右侧抽屉，宽 720px（详情 880px）。
- 抽屉结构：顶部固定条（编号 + 状态 + 责任人）/ 可滚内容 / 底部固定操作区（右对齐，主按钮最右）。
- 抽屉内同时展示当前单据摘要，避免审批人来回切页。
- 弹窗宽 480px，标题 16px，按钮右对齐，危险确认主按钮为红色实底。

## 7. 分页

- 右对齐，`共 N 条` + 页码 + `10/20/50 条/页` + 跳转。
- 页码按钮 28×28，当前页深蓝底白字。

## 8. 其他

- 时间轴：左侧 2px 竖线 `#DCE5E8`，节点 8px 圆点，事件标题 14px，时间 12px 灰。
- 上传：拖拽区虚线 `#C9D6DA`，hover 边框 `#237A8B`；已上传显示缩略图 + 文件名 + 大小 + 删除；显示进度条。
- 面包屑：12px，`#5B6E77`，最后一级 `#1C2B33`。
- 加载：超过 300ms 显示表格骨架，不整页白屏。
- 空状态插图：单色线性，48px，不用插画风。
