# 供应商准入与绩效评价管理系统 · 设计系统

> 设计方向遵循需求文档「UI 视觉与交互设计」一节：公共服务蓝、专业业务系统风格，强调数据可读性、操作效率与状态辨识。
> 不使用巨幅英文口号、装饰光效、悬浮球、过度渐变、大面积插画。

## 1. 视觉关键词

克制、可信、可核对。页面像单位内部系统，而不是营销官网。所有视觉重量集中在数据本身：数字用等宽数字特性，状态用「颜色 + 中文标签」双编码。

## 2. 色彩

| 令牌 | 色值 | 用途 | 使用比例 |
|---|---|---|---|
| `--c-primary` | `#15344A` | 顶部栏底、主按钮、当前菜单、关键数字 | 主结构色，约占 50% 深色面积 |
| `--c-primary-hover` | `#1E4A66` | 主按钮 hover、菜单 hover | — |
| `--c-secondary` | `#237A8B` | 次级按钮、筛选选中态、普通图表系列 | 约 20% |
| `--c-accent` | `#2D5B6B` | 链接、信息提示、图表对比系列 | 约 12% |
| `--c-bg` | `#F3F7F8` | 内容区背景 | 大面积 |
| `--c-surface` | `#FFFFFF` | 卡片、表格、表单容器 | 大面积 |
| `--c-border` | `#DCE5E8` | 分割线、表格边框 | 线 |
| `--c-text` | `#1C2B33` | 正文 | — |
| `--c-text-2` | `#5B6E77` | 次要说明、表头 | — |
| `--c-text-3` | `#8A9AA2` | 占位、禁用 | — |
| `--c-success` | `#2D7A58` | 已准入、已完成、正常 | 小面积 |
| `--c-warning` | `#A9701F` | 即将到期、整改中、超时预警 | 小面积 |
| `--c-danger` | `#B03035` | 驳回、黑名单、删除确认 | 只做小面积提示 |
| `--c-info-bg` | `#EAF1F3` | 标签底色、选中行底 | — |

状态色不做大面积铺底，标签使用 `底色 8% + 文字 100%` 的组合，保证表格可读。

## 3. 字体阶梯

系统中文字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif`。
数字列追加 `font-variant-numeric: tabular-nums`。

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 22 / 30 | 600 | 页面标题（每页唯一） |
| H2 | 16 / 24 | 600 | 卡片标题、抽屉标题 |
| Body | 14 / 22 | 400 | 正文、表格内容 |
| Label | 13 / 20 | 400 | 表单标签、表格表头 |
| Caption | 12 / 18 | 400 | 辅助说明、时间戳 |
| Metric | 28 / 34 | 600 | 看板核心指标数值（tabular-nums） |

## 4. 圆角、阴影、间距

- 圆角：卡片/容器 `8px`，按钮/输入框 `6px`，标签 `4px`，头像圆形。
- 阴影：仅抽屉、弹窗、下拉浮层使用 `0 8px 24px rgba(21,52,74,.12)`；卡片不用阴影，用 1px 边框区分层级。
- 间距基数 4px，常用 8 / 12 / 16 / 24。内容区外边距 24px。
- 卡片内边距 20px；表格单元格 10px 14px。

## 5. 页面框架

- 桌面端：左侧菜单 220px（折叠 64px）+ 顶部栏 56px + 自适应内容区。
- 顶部栏只放面包屑、全局消息、帮助、个人头像。
- 内容区结构：筛选区（白底卡片）/ 操作条 / 表格区 / 分页。
- 表单：标签宽 100–120px，单列输入 360–520px；搜索下拉 180–240px。
- 详情页顶部固定条：业务编号 + 状态标签 + 责任人 + 创建时间 + 最近更新时间。

## 6. 双端视觉区分

| | 内部管理端 | 供应商门户 |
|---|---|---|
| 色彩 | 主色深蓝 `#15344A` 侧边栏 | 辅助色 `#237A8B` 顶栏 + 浅色导航 |
| 布局 | 侧边栏 + 顶栏 + 表格密集型 | 顶部导航 + 内容流 + 大卡片 |
| 信息密度 | 高（表格 10 行/屏） | 中（卡片式，每屏 3–4 块） |
| 语气 | 待办、审核、批量 | 我的企业、我的申请、进度提示 |

## 7. 图表规范

- 系列色序：`#15344A` → `#237A8B` → `#2D5B6B` → `#7FA6B0` → `#A9701F` → `#2D7A58`。
- 网格线只保留横向，`#E8EEF0`，不画纵向网格。
- 折线 2px，数据点 4px 空心；柱状图圆角 3px。
- 每个图表必须有中文标题与单位说明，图例统一放右上。
- 点击图形跳转到带对应筛选条件的列表。

## 8. 状态双编码对照

| 状态 | 色 | 标签 |
|---|---|---|
| 已准入 / 合格 / 已完成 | success | 实心浅绿底 + 文字 |
| 待审批 / 评审中 / 整改中 | warning | 浅橙底 + 文字 |
| 已驳回 / 黑名单 / 暂停 | danger | 浅红底 + 文字 |
| 草稿 / 待提交 / 已退出 | 中性灰 | 浅灰底 + 文字 |
| A 级 | success | 徽标 `A` |
| D 级 / 高风险 | danger | 徽标 `D` |

不允许只靠颜色表达状态，标签内必须有中文。
